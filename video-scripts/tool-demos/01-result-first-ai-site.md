# Script 1: Result first (AI site build)

- **Hook type:** Result first
- **Length:** about 30 seconds
- **Note:** Replace every [X] with a real, recorded figure before posting.

| Time | On screen | Voiceover |
|---|---|---|
| 0-2s | The finished site, scrolling. Text: **"Built with one prompt"** | "This site took [X] minutes. No code written by me." |
| 2-6s | Cut to the blank terminal or editor. | "Here's exactly what I typed." |
| 6-14s | Show the prompt typed out. Highlight the specific parts (audience, pages, style). | "Not 'make me a website.' I said who it's for, what pages it needs, and how it should look." |
| 14-22s | Sped-up build, then the first result loading. | "It built this. One thing was off, so I fixed it with a second message." |
| 22-27s | Before and after of the fix. | "That's the whole workflow." |
| 27-30s | Face the camera or hold on the site. Text: **"Which tool should I test next?"** | "Tell me which tool to try next." |

**Caption:** Built this in [X] minutes. Prompt in the video. #aitools #webdesign #buildinpublic
