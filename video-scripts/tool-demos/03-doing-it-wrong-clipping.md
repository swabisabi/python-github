# Script 3: "You're doing it wrong" (clipping long video)

- **Hook type:** "You're probably doing this wrong"
- **Length:** about 30 seconds
- **Note:** Replace every [X], [Y], [N] and [tool] with real, recorded values. Check the licence of any footage you run through a clipping tool (see `../clip-strategy.md`).

| Time | On screen | Voiceover |
|---|---|---|
| 0-3s | A long video timeline you scrub through by hand. Text: **"Still cutting clips by hand?"** | "If you still scrub through long videos to find the good bits, you're doing it the slow way." |
| 3-9s | Screen recording of manual cutting, sped up with a visible timer. | "This took me [X minutes] for one clip." |
| 9-17s | Upload the same video to a clipping tool. Show it processing. | "Now the same video in [tool]." |
| 17-24s | The tool's suggested clips appear. Play one for a second or two. | "It suggested [N] clips. This one's usable as is." |
| 24-27s | Be honest on screen: show one clip you'd reject. | "Not every clip is good. You still pick the best ones." |
| 27-30s | Text: **"Want the full workflow?"** | "Follow for the full workflow." |

**Caption:** Same video, two ways. [X] minutes versus [Y] minutes. #videoediting #contentcreator #aitools
